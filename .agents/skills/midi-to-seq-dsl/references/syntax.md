# Sequence DSL — MIDI 변환 참조

## 기본 표기

```text
$ Title
- Seq 1
~sin1:1 +sin2:0.1
!a10 !d1000 !s20 !r400
*bpm120

$ 001마디 (4/4)
c4 e4 g4 4 0
8
f4 8 0
```

- `$`부터 해당 줄 끝까지는 주석.
- `- Seq N`은 독립 시퀀스. 여러 시퀀스는 동시에 시작하고 개별 BPM을 가질 수 있음.
- `*bpm120`에서 quarter-note 단위 시간은 0.5초.
- `N`은 박자 수가 아닌 **음표 분모**. `1=4박`, `2=2박`, `4=1박`, `8=0.5박`, `16=0.25박`.
- `{음계...} {길이 분모} {당김 분모}` — 길이와 당김을 별도로 지정.
- `c4 e4 g4 4 0`: C/E/G 화음을 1박 재생.
- `8`: 0.5박 대기. 소수 분모도 사용 가능.
- `c4:c5 4 0`: Sweep; MIDI는 슬라이드 이벤트를 기본 음표로 제공하지 않으므로 **자동 Sweep 추론하지 않음**.
- `0` 당김은 이전 당김의 상속이며, `0박`으로 리셋하는 명령이 아님. MIDI 변환기는 당김이 필요한 경우에도 **다른 시퀀스에 분리**함. 초기 당김 0은 플레이어 측의 전제.

## 시간 정확도

- MIDI PPQ tick ↔ 길이 분모: PPQ=480, 120tick는 16분음표=0.25박 → `16`.
- 60tick는 0.125박 → `32`.
- 200tick는 200/480박 → 분모 `9.6`.
- Precise 모드의 실수 분모는 12자리까지 출력되므로 극소 오차가 있을 수 있음.
- Readable 모드는 기본 16분음표(0.25박) 그리드에 음표 시작과 종료를 맞춤. 16분음표보다 짧은 음도 최소 16분음표로 늘어나며, 구간이 새로 겹치면 추가 Seq가 생길 수 있음.
- BPM 변경은 스코어상의 음가와 다른 실시간 타이밍을 만들므로 기본값으로 MIDI 실제 시각을 한 BPM으로 펴서 처리. 마디 번호/박자표는 원래 MIDI의 메타 이벤트를 따른다.

## 해석 제약

- 음높이: MIDI 60=C4(사용자 악보 옥타브 체계가 다르면 `--middle-c` 변경).
- 조표는 MIDI 음높이와 별도 메타정보이므로, 기본적으로 검은 건반 음들은 #으로 표기.
- 시퀀스 전체 한 음색을 공유; MIDI 악기 변경, 특정 음 velocity, 드럼 소리 등은 보존 불가.
- CC64(서스테인)는 Note Off만 사용해 변환할 경우 소리 길이가 다르게 들릴 수 있음.
- Tempo/type 0/type 1 지원. SMPTE MIDI, type 2 미지원.
